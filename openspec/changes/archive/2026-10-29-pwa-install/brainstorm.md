## Decisions

| # | Question | Answer | Source |
|---|---|---|---|
| D1 | Which page does the icon open? | The page it was added from. The web app manifest has no `start_url`, so it defaults to the page's own address, and its scope defaults to `/`. | Evidence: issue #32 Scope; W3C Web App Manifest defaults |
| D2 | What do the icon label and page `<title>` say? | On a sheet, the `<title>` is "<name> — Hero Slate" and `apple-mobile-web-app-title` is the character's full name. On `/`, both are "Hero Slate". The web app manifest's `name` and `short_name` are "Hero Slate". | User |
| D3 | Should a long name be shortened for the label? | No. The full `name` is used. iPad truncates a long label, and the Player can edit it in the Add to Home Screen dialog. | User |
| D4 | Which theme and background colours? | `BASE.surface`. The web app manifest uses the dark value, the resting default. The page has `theme-color` meta tags for light and dark. | User |
| D5 | Does `theme-color` follow the in-app light/dark toggle? | Yes. The script that runs before the first paint and the toggle both set it to the active mode's surface. | User |
| D6 | What does the placeholder icon show? | Bold "HS" in neutral on-accent (`#ffffff`) on the neutral light accent (`#4a4a42`). On the maskable icon, the letters stay inside the centre safe zone. | User |
| D7 | Which icon files? | 180 px `apple-touch-icon`, 192 px, 512 px and 512 px maskable PNGs in `static/`. | Evidence: issue #32 Scope |
| D8 | How is the web app manifest made? | A script generates it from `palette.ts`, the same way `palette.css` is generated. The file is committed and regenerated by `npm run build`. A test fails when it does not match the palette. | Evidence: issue #32 Relevant code; `scripts/generate-palette-css.ts` |
| D9 | How are the icons made? | A script draws the icons with `sharp` from an SVG in palette colours. The PNGs are committed, but the build does not regenerate them, because PNG bytes can change between `sharp` versions. A test checks each icon's size and that its corner pixel is the neutral accent. | User |
| D10 | Is "web app manifest" a glossary term? | Yes. "Character manifest" and "Web app manifest" are now defined in `openspec/glossary.md`, and neither is shortened to "manifest". | User |
| D11 | Does the static-site setup need to change? | No. The web app manifest and icons are ordinary static assets. The deployed site serves them before the single-page fallback, the same way it serves character files. | Evidence: `deployment` spec, SPA fallback requirement |
